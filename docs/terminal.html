The Terminal

[ Contents | Getting started | The desktop | Shortcuts | Files | Apps | Terminal | Help ]

The Terminal is where you type commands. Open it from the start menu or the Finder. Type help to see a list of useful commands.

Easy commands

CcOS has its own easy commands for beginners. Under each one, a grey line shows how you'd do the same thing the usual Linux way, so you learn the real commands too. Type hints off to hide those lines and hints on to bring them back.

CommandWhat it does
mkf hi.txtMake an empty file called hi.txt
mkf hi.txt : hello!Make hi.txt with "hello!" inside
rd hi.txtShow what's inside a file
adf hi.txt : moreAdd text to the end of a file
rn old.txt : new.txtRename a file
cpf hi.txt : usb1Copy a file (to usb1, D:, a folder, or a new name)
rmt hi.txtMove it to the Recycle Bin
op hi.txtOpen it in its app (op google.com opens a website)
lsusbList your USB sticks: usb1, usb2...
cdusb usb1Go into a USB stick. Files you make now go on it
xusbLeave the USB stick
jusb usb1Eject a USB stick safely
spaceFree space on D:, apps and USB sticks
netIs the internet working?
whereamiWhere am I?
hints off / hints onHide or show the grey "usual Linux way" lines

Things to know

  • \n starts a new line in mkf and adf: mkf list.txt : milk \n eggs makes a file with "milk" and "eggs" on two lines.
  • Names with spaces work without quotes: rd my list.txt.
  • Nothing gets overwritten. If a name is taken, the command says so.
  • The Terminal starts in its home folder, which isn't kept after a restart. So in the home folder, mkf puts new files in Documents (D:\Documents), and rd, rn and the others find them there.
  • USB sticks are numbered in the order they were plugged in. If you pull out usb1, the next one becomes usb1.
  • While you're in a stick (after cdusb), the prompt shows usb1.

Example

ccos ~ # mkf shop.txt : milk
✔ Made the file shop.txt in D:/Documents (with your text inside)
  (the usual Linux way: echo milk > /data/Documents/shop.txt)
ccos ~ # adf shop.txt : eggs \n bread
✔ Added 2 lines to shop.txt
ccos ~ # rd shop.txt
milk
eggs
bread
ccos ~ # cpf shop.txt : usb1
✔ Copied shop.txt to usb1 (KINGSTON)
ccos ~ # jusb usb1
✔ usb1 (KINGSTON) is safe to pull out now.

Real Linux commands

All the usual Linux commands work too:

CommandWhat it does
ls / llList files (ll: with sizes and dates)
cd FOLDERGo into a folder (cd .. goes up, D: goes to your D: drive)
cp A B / mv A BCopy / move or rename
rm FILEDelete for good (no Recycle Bin!)
mkdir NAMEMake a folder
treeFolders as a tree
nano FILEEdit a text file (Ctrl+S saves, Ctrl+X quits)
cat / less FILEShow / read a file (q quits)
find . -name '*.txt'Find files
zip -r a.zip DIR / unzip a.zipZip a folder / unzip
7z x FILEUnpack .7z, .rar and more
htopRunning programs, CPU and memory (F9 ends one, q quits)
sensorsTemperatures and fans
df -h / free -hFree space / memory
lsblkDisks and USB sticks
lsusb -a / lspciAll USB devices / other devices
ping google.comIs the internet working?
ip aNetwork addresses
curl URLDownload (curl wttr.in shows the weather)
ssh user@hostLog in to another computer (scp copies files)
python3Python (exit() leaves). python3 FILE.py runs a program
pip install NAMEAdd a Python package (kept on the stick)
flatpak install flathub IDInstall an app from Flathub (like the Software Manager)
poweroff / rebootShut down / restart
help COMMANDMore about one command
