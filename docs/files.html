Files and USB sticks

[ Contents | Getting started | The desktop | Shortcuts | Files | Apps | Terminal | Help ]

File Explorer

File Explorer shows CcOS's drives and folders. Your favourites are on the left: Documents (yellow), Images (blue), Downloads (green) and Videos (purple).

  • Double-click a folder to open it, or a file to open it in its app.
  • Selecting: click; Ctrl+click adds or removes one; Shift+click picks a range; Ctrl+A selects all. Or press on an empty spot and drag a box.
  • Copy, cut, paste: Ctrl+C, Ctrl+X, Ctrl+V, the buttons at the top, or right-click. Big copies show a window with progress and Cancel. If a file with the same name is already there, the new one becomes "name (2)".
  • Dragging: drag files onto a folder or a place on the left. On the same drive it moves them, to another drive it copies them (hold Ctrl to always copy).
  • Rename: F2. Search: the box at the top right, or Ctrl+F.
  • Right-click empty space > New: Folder, Text Document, Web Page, Shell Script, Markdown Notes, CSV Spreadsheet or Zip File.

You can only change things on D: (and USB sticks). C: is CcOS itself.

The Recycle Bin

Delete moves files to the Recycle Bin. It's on the desktop and on the left in File Explorer, and it shows where each file came from and when. Restore puts a file back; Empty Recycle Bin deletes them for good. Shift+Delete skips the Recycle Bin.

Files on USB sticks can't go to the Recycle Bin, so they're deleted straight away (CcOS asks first).

Zip files

Right-click > Compress to zip packs your selection into one .zip file. Double-click a .zip (or right-click > Extract all) to unpack it. .rar, .7z, .tar, .tar.gz, .tar.xz and .tar.bz2 unpack the same way (but not ones with a password).

USB sticks and drives

  1. Plug it in. A notification says it's ready.
  2. It shows in File Explorer, under Computer > Removable Drives and on the left.
  3. Before pulling it out, click the eject button next to its name (or right-click > Eject) and wait for "Safe to remove".

FAT32, exFAT, NTFS, ext4 and CDs work. In the Terminal, lsusb, cdusb and jusb do the same things (see The Terminal).

Printing

In Photos click the printer button (or Ctrl+P), or in File Explorer right-click a picture > Print. CcOS finds printers on your Wi-Fi by itself (most printers from the last 10 years, anything with AirPrint or "IPP Everywhere"), with no drivers needed. If yours isn't found, type its IP address under "Not listed?".

When apps want a file

When an app wants a file ("Upload", "Open..."), a file window appears with your Documents, Images, Downloads, Videos and USB drives on the left.
