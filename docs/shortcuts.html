Keyboard shortcuts

[ Contents | Getting started | The desktop | Shortcuts | Files | Apps | Terminal | Help ]

Every shortcut in CcOS. Win means the Windows key.

Everywhere

KeysWhat it does
WinOpen or close the start menu (or the Finder, with the Dock)
Win + SpaceQuick Search: apps, settings, files, and web searches or addresses
Alt + TabSwitch windows: hold Alt, tap Tab, let go. Shift goes back, Esc cancels
Win + TabTask View: all windows and your desktops
Win + Ctrl + Left / RightGo to the desktop before / after
Win + Ctrl + DA new desktop
Win + Ctrl + F4Close this desktop (its windows move to the one before)
Win + Ctrl + Shift + arrowsTake the active window to the next desktop
Win + arrow keysSnap the window: left / right half, Up maximizes
F11Full screen and back
Win + VClipboard history: the last 25 things you copied
Win + . or Win + ;Emoji picker
Win + PSecond screen: PC only / Duplicate / Extend / Second screen only
PrtScScreenshot of the whole screen (saved in Images > Screenshots, and copied)
Win + Shift + SScreenshot of part of the screen (drag a box, Esc cancels)
Win + Alt + RStart / stop recording the screen
EscClose the menu
Volume keysVolume up / down / mute
Brightness keysScreen brightness
Ctrl + Alt + BackspaceLeave the desktop to the command line (type desktop to go back)

File Explorer

KeysWhat it does
Ctrl + C / X / VCopy / cut / paste
Ctrl + ASelect everything
Ctrl + clickAdd or remove one from the selection
Shift + clickSelect a range
DeleteMove to the Recycle Bin
Shift + DeleteDelete for good
F2Rename
Ctrl + FSearch this folder and everything in it
Ctrl + dragCopy instead of move

Notepad

KeysWhat it does
Ctrl + N / O / SNew / Open / Save
Ctrl + A / C / X / VSelect all / copy / cut / paste
Shift + arrows, Home, EndSelect text

Terminal

KeysWhat it does
Ctrl + Shift + C / VCopy / paste
TabFinish a name (Tab Tab shows the choices)
Up / DownEarlier commands (type the start first to narrow them)
Ctrl + RSearch earlier commands
Ctrl + LClear the screen
Ctrl + CStop the running program

Python app

KeysWhat it does
F5Run the program
Tab / Shift + TabIndent / unindent (4 spaces)
Ctrl + /Comment or uncomment lines
Ctrl + Z / YUndo / redo
Ctrl + DDuplicate the line

Paint

KeysWhat it does
Ctrl + Z / YUndo / redo
Ctrl + VPaste the last copied picture (like a screenshot)
Ctrl + SSave to Images

Photos

KeysWhat it does
Left / RightThe picture before / after
+ / - or the mouse wheelZoom
0Fit it to the window
Ctrl + PPrint
Double-clickFull screen

Videos

KeysWhat it does
Space or clickPause / play
Left / Right5 seconds back / forward
F or double-clickFull screen

PDF viewer

KeysWhat it does
Left / Right, < >Pages
Ctrl + plus / minusZoom

Games and Calculator

KeysWhat it does
F2New game (Solitaire, Minesweeper)
Numbers, + - * /, EnterCalculator works from the keyboard; Esc clears

X11 apps (older apps and games)

KeysWhat it does
Alt + dragMove a window inside the X11 apps window
F11Make the X11 apps window full screen
