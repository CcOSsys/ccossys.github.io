When things go wrong

[ Contents | Getting started | The desktop | Shortcuts | Files | Apps | Terminal | Help ]

The screen stays black when it starts

Restart, open the boot menu again, pick the stick, and choose ccos (safe graphics) in the menu that shows for 3 seconds.

"CcOS needs to find your USB boot stick"

Some computers find USB sticks a few seconds late. Unplug the stick and plug it back in. When it says "USB boot stick found!", the desktop opens with your settings. Skip (or Esc) opens the desktop straight away.

A [ FAIL ] line while starting

A red [ FAIL ] means one step didn't work. CcOS keeps going if it can. If the desktop itself fails, you stay on that screen with a command line, so you can type commands:

  • desktop - try to start the desktop again
  • help - a list of commands
  • reboot - restart

If the desktop crashed, what went wrong is written in /tmp/ccos-crash.txt (type cat /tmp/ccos-crash.txt).

The purple "KERNEL PANIC!" screen

That's Linux itself crashing (very rare). It shows Tux and the reason. CcOS restarts by itself after a few seconds, or you can hold the power button.

The desktop froze or is acting weird

  • Press Ctrl + Alt + Backspace to leave the desktop, then type desktop to start it again.
  • If CcOS freezes for a second or more, it writes down what it was waiting for in D:\ccos-freeze-log.txt. Handy for bug reports.

An app won't start or misbehaves

  • If you turned on Settings > About > "Let apps draw with the graphics chip", turn it off and restart the app.
  • The first Flathub app downloads a few hundred MB first, so give it time.

No internet

Click the network icon next to the clock and pick your Wi-Fi. In the Terminal, net tells you what's wrong.

Windows shows the wrong time after using CcOS

Turn on Settings > Clock > "Windows is on this computer too". Then both show the right time.

Windows says the stick needs formatting

Click Cancel. Never format the CcOS stick from Windows, or your CcOS files and apps are gone.

Starting over

Writing the stick again with Rufus starts completely fresh, but it erases all your CcOS files and apps too. Copy anything you want to keep to another USB stick first.
