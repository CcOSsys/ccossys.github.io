The very short version

  • The Windows key opens the start menu (or the Finder, with the Dock).
  • Your files live on D:, which is on the USB stick. They're kept after a restart.
  • New apps come from the Software Manager (the orange bag).
  • In the Terminal, type help to see what you can type.
  • To turn CcOS off, use Shut down in the start menu. Don't just pull the stick out.
