tinyCcOS 0.1 beta

The tiny, plain version of CcOS for old computers (and potatoes). What is it?

DownloadForSize
tinyCcOS 0.1 beta (64-bit) Most computers from about 2008 on. Pick this one if you're not sure. 76 MB
tinyCcOS 0.1 beta (32-bit) Really old computers that can't run 64-bit: Pentium 4, Pentium M, the first Atom netbooks. More about it 76 MB

All files and older versions: tinyc releases on GitHub. Source code: github.com/CcOSsys/tinyc (MIT licence).

What you need

  • A USB stick of 2 GB or more. Everything on it will be erased.
  • A computer with at least 256 MB of memory.
  • To write the stick: Rufus (Windows) or balenaEtcher (Windows, Mac, Linux).

How to put it on a USB stick

  1. Download one of the files above. You don't have to unzip it: Rufus and balenaEtcher can read the .img.gz file as it is.
  2. Plug in the USB stick and open Rufus (or balenaEtcher).
  3. Pick the USB stick, then click SELECT and pick the file you downloaded.
  4. Click START (or Flash!). If Rufus asks how to write it, pick DD image mode. Wait until it's done.
  5. Plug the stick into the computer you want to use, start it and open the boot menu (often F12, sometimes F9, F10, F11 or Esc). Pick the USB stick.

On Linux you can also write it in the Terminal (change sdX to your stick, and be careful to pick the right one):
zcat tinyCcOS-0.1-beta-64bit.img.gz | sudo dd of=/dev/sdX bs=4M status=progress

The first start takes a bit longer, and tinyc always needs its USB stick to start. Everything else is in the tinyCcOS docs.
